# Veklom Agent Handoff Packet

Every department-to-department handoff must be explicit and evidence-aware. Never send vague requests such as “fix this”, “make it work”, or “deploy it”.

Required fields: owning department, requested action, repository, branch, commit SHA, risk level, production/security impact, proof required, forbidden actions, and next owner.

Only the owning department may declare its lane complete. Release Control and Production Truth close production-impacting work. Security & Secrets clears exposure risk. Runtime Governance clears permit/enforcement claims. Evidence & Ledger clears proof claims.
