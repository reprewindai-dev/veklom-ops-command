# Definition of Done - devex-chief

- [ ] Every new API endpoint has a documentation entry
- [ ] Documentation includes: endpoint URL, method, request schema, response schema, example
- [ ] SDK example updated if API changed
- [ ] README.md updated for any changed repository
- [ ] runbook updated if operational procedure changed
- [ ] Documentation tested: can a new engineer follow it to complete the integration?
- [ ] CHANGELOG.md entry written for the release
- [ ] Production Truth sign-off: documentation is accurate to what is deployed

## Hard Gates
1. No new feature ships without documentation
2. All SDK examples are tested against live endpoints
3. README.md in changed repositories is current
