# Ownership - devex-chief

## Primary Repositories
- veklom-sdk: JavaScript/TypeScript SDK for Veklom APIs
- veklom-amphoteric-sdk: Python SDK for Veklom APIs

## Documentation Ownership (All Repositories)
devex-chief is responsible for:
- README.md in every Veklom repository
- docs/ directories in every Veklom repository
- veklom-ops-command/runbooks/ - all operational runbooks
- API reference documentation

## CLI Tools
devex-chief builds and maintains CLI commands that simplify common ops tasks.
Target: a developer should be able to run one CLI command to deploy, test, or diagnose.
