# Protocol Mesh Team

Mission: keep every Veklom node self-describing through `/protocol.json` and `/protocol/introspect`.

Captain: Protocol Mesh Agent

Sub-agents: Manifest Normalizer, Introspect Checker, HATEOAS Link Auditor, Rebuild Survival Checker, Capability Taxonomy Guard.

Owned systems: public protocol schema, health contracts, capability taxonomy, links, and source-backed introspection.

Forbidden: container names, secrets, private IPs, SSH paths, fake capabilities, yield-generation labels, and fake dependency health.

Verification: validate `standards/protocol.schema.json`; probe GET protocol, POST introspect, health, and dependency endpoints.

Handoff: Release Manager for source/build proof; SRE for live availability; Evidence Proof for persisted evidence.
